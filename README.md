# 🔓 Distortionz Picklocks

**Distortionz Picklocks** is a FiveM/Qbox lockpicking resource built for immersive illegal roleplay, vehicle theft, and configurable lockpick gameplay.

## ✨ Features

- 🔓 Lockpick item support
- 🚗 Vehicle lockpicking gameplay
- 🎯 Optional `ox_target` interaction support
- 📦 `ox_inventory` item support
- 🔔 `ox_lib` notification support
- 🧩 Configurable lockpick difficulty
- ⏱️ Configurable cooldowns
- 🛠️ Configurable lockpick break chance
- 👮 Optional police alert support
- ⚙️ Easy configuration through `config.lua`
- 🧼 Clean and simple resource structure

## 📦 Dependencies

- `ox_lib`
- `ox_inventory`
- `qbx_core` or `qb-core`

Optional:

- `ox_target`
